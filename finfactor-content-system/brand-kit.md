# Finfactor — LinkedIn Brand Kit

## Logo
- Wordmark: "Finfactor" with diamond mark, white on dark, purple on light
- Placement: top-left, ~64px from top and left edges
- URL: "finfactor.ai", bottom-right, ~64px from bottom and right, 
  Geist Regular, muted (60% opacity)

## Color palette

Brand purple (primary):     #5B47E0   (saturated, used as ground)
Deep purple / near-black:   #0B0820   (dark mode ground)
Off-white / lavender tint:  #F4F2FA   (light mode ground)
Pure white:                 #FFFFFF   (card surfaces)
Ink / body text:            #0B0820
Muted text:                 #6B6480
Accent coral (myth/wrong):  #E85A5A
Accent coral background:    #4A1818   (dark mode pill bg)

Grid lines:
- On purple/dark:  white at 8% opacity
- On light:        purple at 8% opacity

## Fonts

Display (headlines, quotes, hooks):
  Playfair Display Italic
  - Weights: 400 (italic), 700 (bold italic for emphasis words)
  - Default tracking (no negative letter-spacing)
  - Use italic as default, not upright

Sans (everything else — labels, attribution, body, UI):
  Geist
  - Regular (400) — body, captions, URLs
  - Medium (500) — names, slide body copy
  - Semibold (600) — small labels, pill text, navigation
  - Bold (700) — rare, only when sans needs to carry a headline

Size system (1080x1080 / 1080x1350):
  - XL display:    96–120px   (single-image hero quote)
  - L display:     72–88px    (carousel slide 1 hook)
  - M display:     48–60px    (section headers)
  - Body:          28–36px
  - Small/label:   18–22px
  - URL/caption:   16–18px

Max 3 type sizes per creative, each tied to a distinct role.

## Background modes

LIGHT:   off-white/lavender ground (#F4F2FA) with purple grid
DARK:    near-black ground (#0B0820) with white grid, subtle 
         purple gradient wash
BRAND:   saturated purple ground (#5B47E0) with white grid 
         (use for quote/leader cards specifically)

Single-image / infographic: ASK which mode before building.
Carousel: ALTERNATE light → dark → light → dark by default. 
          Brand purple used only for dedicated quote slides.

## Signature elements (use, don't reinvent)

1. Faint grid overlay on every background — non-negotiable.
2. Oversized decorative quotation marks (open top-left, close 
   bottom-right) for any quote treatment.
3. White rounded-rect card with offset dark shadow for quote 
   content on brand-purple or light grounds.
4. Pill labels with icons for binary comparisons 
   (myth/reality, before/after, wrong/right):
     - Wrong/myth: coral pill, x icon
     - Right/reality: purple pill, check icon
     - Slight rotation (~-3° to +3°) on stacked pill cards
5. Italic serif for the emotional/quotable line; sans for 
   structural/labeling text. Never reverse.
6. Bolded word within an italic serif phrase to anchor 
   the key idea (e.g., "manage **risk**", "manufacture **opportunity**").

## Spacing & layout
- 64px margin from canvas edges
- Card padding: 56–72px internal
- Generous vertical breathing room; never fill the canvas

## Don'ts
- No upright Playfair for display — always italic.
- No new colors outside the palette.
- No grid-less backgrounds.
- No more than one accent color (coral) per creative.
- No centered headlines unless the composition specifically calls for it.
